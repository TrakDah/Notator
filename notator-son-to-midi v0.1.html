Notator song recovery

Reads an Atari ST Creator/Notator .SON file and writes standard MIDI files: the whole arrangement as a single file with the Arrange mutes applied, plus one file per pattern. Everything happens in this page — your file is never uploaded anywhere.

Arrangement

What to export

Notator could never export the per-occurrence Arrange mutes, so a pattern with several bass variants always played all of them at once. This reads those mute bits and applies them. The reading is corroborated by the musical structure it produces but has not been checked against original hardware playback, so listen before you trust it.
